# Beamix iOS Shortcut — Capture Idea

Voice-to-Linear ticket creation via Apple Shortcuts + Anthropic Haiku + bridge `/idea-capture`.

## What it does

1. Prompts Adam for voice input (Dictate Text action — press Home button or say "Hey Siri, Capture Beamix Idea").
2. Checks for empty dictation — shows alert and exits if nothing was recorded (R6 safety check).
3. Sends the voice transcription to Anthropic Haiku to convert into a clean Linear ticket title + body + UUID nonce.
4. POSTs the result to `https://beamix-bridge.workers.dev/idea-capture` with an HMAC signature and Unix timestamp.
5. Shows a success notification "Idea captured ✓ — BMX-XXX" or "Capture FAILED: <error>" based on bridge response (R6 — no silent failures).

## Importing on iPhone

1. Open the `Capture-Beamix-Idea.shortcut.json` file on your iPhone (via AirDrop from Mac, or iCloud Drive, or email attachment).
2. Tap "Open in Shortcuts" when prompted.
3. Shortcuts will import the workflow automatically.
4. Tap the shortcut to open it, then tap the "..." (edit) button to configure your secrets (see below).

Alternatively, you can add it to Siri: Settings → Siri & Search → Add Shortcut → "Capture Beamix Idea".

## Required configuration inside the Shortcut

Before using, you must update two values in the Shortcut editor:

### 1. Anthropic API key (Step 3 — URL action headers)
Replace `YOUR_ANTHROPIC_API_KEY_HERE` in the `x-api-key` header with your actual `ANTHROPIC_API_KEY` (Console-billed, not subscription OAuth — per `feedback_claude_code_oauth_ban_risk.md`).

**See Keychain option below** for storing the API key securely without hardcoding it.

### 2. HMAC signature (Step 7 — X-Beamix-Signature header)

The signature must be `sha256=HMAC-SHA256(SHORTCUT_SECRET, TimestampSeconds + "\n" + RequestBody)`.

`TimestampSeconds` is a Unix epoch integer (e.g. `1715166000`), available as the `TimestampSeconds` variable from Step 5b.

Apple Shortcuts does not have a native HMAC action. Two options:

**Option A: Haiku-computed HMAC (simplest — no native crypto needed)**
Add an additional URL action before Step 7 that calls a tiny bridge-side signing endpoint:
```
POST https://beamix-bridge.workers.dev/sign-shortcut-payload
Body: { "payload": <TimestampSeconds + "\n" + RequestBody> }
Headers: X-Shortcut-Preshared-Token: <a separate low-risk token Adam sets>
```
The bridge signs it server-side and returns the signature. This avoids storing `SHORTCUT_SECRET` in the Shortcut itself.

**Option B (recommended for non-disposable keys): Keychain via Shortcuts**
Store `SHORTCUT_SECRET` in your iPhone's Keychain (iCloud Keychain synced). Retrieve it inside the Shortcut using the "Find in Password Manager" action (requires Shortcuts + 1Password integration, or the built-in Shortcuts Keychain action in iOS 17+):

1. Open Settings → Passwords → Add a new entry: Service = `beamix-shortcut`, Username = `bridge`, Password = `<your SHORTCUT_SECRET value>`.
2. In the Shortcut, add a "Get Password" action (Shortcuts Keychain) before Step 7:
   ```
   Get Password for "beamix-shortcut" → store as KeychainSecret
   ```
3. Use `KeychainSecret` as the pre-shared secret to compute HMAC (via Option A bridge endpoint, or a local HMAC library if your iOS version supports it).

**Why Keychain for non-disposable keys?** If your iPhone is compromised and `SHORTCUT_SECRET` is hardcoded in the Shortcut, it can be extracted from the iCloud Shortcuts backup. Keychain-stored secrets are encrypted at rest and require device unlock + biometrics to access. For MVP, Option A is acceptable. Upgrade to Keychain before production.

For MVP: Option A is acceptable. Keychain (Option B) is recommended for long-lived production deployments.

## Security contract (R3)

The bridge verifies HMAC over `TimestampSeconds + "\n" + body` with a ±300s timestamp skew window.

The JSON body sent to the bridge must include a `nonce` field (UUID v4) generated by Haiku in Step 3. The bridge deduplicates on this nonce with a 24h KV window — replay attacks within the 90-day rotation window are blocked.

## Rotating SHORTCUT_SECRET

Per `secret-rotation.md` row #5:
1. Generate new secret: `openssl rand -hex 32`
2. Update Cloudflare Worker: `wrangler secret put SHORTCUT_SECRET`
3. Deploy: `wrangler publish`
4. Update the secret value in your Shortcut (via the edit button) and re-save. If using Keychain (Option B), update the Keychain entry instead.

## Bridge endpoint details

`POST https://beamix-bridge.workers.dev/idea-capture`

Required headers:
- `X-Beamix-Signature: sha256=<hex>` — HMAC over `TimestampSeconds + "\n" + body`
- `X-Beamix-Timestamp: <unix-epoch-seconds>` — must be within ±300s of server time

Expected body:
```json
{
  "title": "Short ticket title (max 500 chars)",
  "body": "Optional longer description",
  "nonce": "uuid-v4-generated-by-haiku",
  "labels": ["optional", "label", "array"],
  "timestamp": "2026-05-08T10:00:00Z"
}
```

Response (200 success):
```json
{ "ok": true, "ticket_id": "...", "identifier": "BMX-123" }
```

Response (error):
```json
{ "error": "description of failure" }
```

The Shortcut reads `status_code` and `identifier` / `error` from the response to show the correct notification.
