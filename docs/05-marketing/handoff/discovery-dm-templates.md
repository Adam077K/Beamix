## Instructions before sending

1. Run a free scan on their website BEFORE messaging — reference specific findings
2. Check their LinkedIn for recent activity — reference something real if possible
3. Personalize the [bracketed fields] — don't send template text verbatim
4. Send from Adam's personal LinkedIn, not the Beamix company page
5. Max 150 words. If it's longer, cut it.
6. One CTA only: a 30-minute discovery call slot.

## What NOT to do

- Don't say "I hope this finds you well"
- Don't list every feature Beamix has
- Don't send without running their actual scan first
- Don't follow up more than once
- Don't message from the Beamix brand page — this is founder-to-founder
- Don't use "leverage," "enable," "synergy," or any banned words (CONTENT_STYLE_GUIDE.md §4)
- Don't call Beamix a "platform" or "tool" — it's an agency
